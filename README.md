# 🍽️ Hostel Mess Management System

A web-based Hostel Mess Management System designed to make hostel food information easily accessible to students. Students can view daily mess menus and explore meal details for different days through a simple, user-friendly interface.

## 🌐 Live Website

[Visit Hostel Mess Management System](https://greeshmajada-netizen.github.io/Hostel-Mess-Management/)

## 📌 About the Project

The Hostel Mess Management System aims to simplify the way students access hostel mess information. Instead of depending on notice boards or manually asking about daily meals, students can conveniently check the mess menu online.

The website focuses on presenting meal information in an organised manner with an easy-to-use interface.

## 🎯 Objectives

- Provide easy access to daily hostel mess menus.
- Display breakfast, lunch, snacks and dinner details.
- Organise menu information according to days.
- Improve access to mess-related information.
- Create a simple and user-friendly website.

## ✨ Key Features

- **Daily Menu:** View hostel food menus for different days.
- **Meal Categories:** Separate sections for breakfast, lunch, snacks and dinner.
- **Easy Navigation:** Simple interface for browsing menu information.
- **User-Friendly Design:** Clean and organised website layout.
- **Responsive Interface:** Designed for convenient browsing across screen sizes.

## 🚀 How to Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/greeshmajada-netizen/Hostel-Mess-Management.git
   ```

2. Open the project folder:

   ```bash
   cd Hostel-Mess-Management
   ```

3. Open `index.html` in your web browser. Alternatively, open the folder in Visual Studio Code and use the Live Server extension.
